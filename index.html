Tour Visualiser

An interactive map of the campus tour route. Each stop shows the script to read and any relevant notes, so you can review the tour at your own pace.

How to Use

  • Pan: click and drag the map to pan around it.
  • Zoom: use the scroll wheel, the + and - buttons, or double-click to zoom in and out
  • Stops: hover over a marker to see its name or click it to open that stop.
  • Tour: press the start tour button below to take the tour step by step.
  • Marker Mode: press the m key with the map selected to enable marker placement mode. This allows the creation of custom tour routes.

Placed Markers

Welcome to marker placement mode. Use this panel to create new tours by clicking the map to place a marker there. Each marker placed will create a template for you. The id, lat, and lng values are meaningful and shouldnt be changed.

Once done, click the copy JSON button, or copy directly from the text field to copy your custom stops array!
